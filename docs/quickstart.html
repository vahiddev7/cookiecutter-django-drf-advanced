Getting started

Generate a Django project with Cookiecutter

This guide walks through creating a new Django backend from the Django DRF Advanced Cookiecutter template.

1. Install Cookiecutter

Use Python's package installer to install Cookiecutter:

python -m pip install --upgrade cookiecutter

2. Generate the project

Run Cookiecutter with the template repository URL:

cookiecutter https://github.com/vahiddev7/cookiecutter-django-drf-advanced

Answer the prompts to choose a project name and optional integrations. See the configuration guide for an overview of the available options.

3. Review environment settings

The generated project includes an .env.example. Review the generated local environment values, database credentials, and service URLs before running the application. Never commit production secrets or a real .env file.

4. Start the project

If Docker was enabled during generation, start the containers from the generated project directory:

docker compose up --build

If Docker was not selected, install the generated development dependencies and follow the project's local setup instructions.

5. Create an application

Generated projects include an app-generation script. For example:

./scripts/start_app.sh blog

Review the generated application and add only the modules needed for its responsibilities.

Before production use, review allowed hosts, secret management, database access, API permissions, CORS, CSRF, HTTPS, and deployment-specific settings.
