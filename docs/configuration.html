Template options

Configure your generated Django project

The template uses Cookiecutter prompts to include only the integrations selected for a project. The available options are defined in the repository's cookiecutter.json.

Django REST Framework

Enable or disable Django REST Framework. The authentication application is generated when DRF is enabled.

API documentation

Choose whether to include the configured Swagger/OpenAPI support. This option is relevant when DRF is enabled.

Docker

Choose whether the generated project includes the Docker development setup and compose configuration.

Database engine

Select one of the configured database backends:

  • PostgreSQL
  • MySQL
  • SQLite
  • SQL Server

Database drivers and operational requirements differ. Verify the selected backend in your target environment.

Celery and message broker

Enable Celery for background task processing, then select Redis or RabbitMQ as the broker. The broker choice applies when Celery is enabled.

Cloud storage

Choose local filesystem storage, AWS S3 (including S3-compatible endpoints), Google Cloud Storage, or Azure Blob Storage. When a cloud provider is selected, its media and static-file settings live in config/settings/storage.py, separate from the base settings module; that file is omitted entirely for the local-filesystem option. Configure credentials through environment variables or workload identity; never commit secrets. Run python manage.py collectstatic after configuring the provider.

Logging and error monitoring

Console logging is configured separately from the base settings and its verbosity is controlled by LOG_LEVEL. Sentry is optional: select it during project generation, then configure SENTRY_DSN and sampling settings through environment variables. Sentry remains inactive when no DSN is provided.

Choosing options

Start with the smallest set of integrations your application needs. You can add infrastructure as requirements become clearer, but changes to generated configuration should be tested against the selected database and service combination.
