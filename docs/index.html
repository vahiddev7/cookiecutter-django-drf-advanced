A configurable Python Django project generator

This open-source Django Cookiecutter template helps developers create a consistent backend foundation for web applications and REST APIs. Instead of copying an old project or manually assembling settings, select the integrations you need when generating a new project. The generated files depend on your Cookiecutter answers, so optional components are not forced into every application.

What can you generate?

The Cookiecutter prompts configure separated Django settings and optional integrations for Django REST Framework, PostgreSQL, MySQL, SQLite, SQL Server, Redis, RabbitMQ, Celery, Docker, Sentry, and cloud object storage. Read the configuration guide for the available options.
