## [0.1.0] - 2026-11-02

Initial feature-complete pre-1.0 release candidate of the Cookiecutter template.

### Added
- Configurable Django project scaffold with separated base, development, and production settings.
- Optional Django REST Framework integration, authentication endpoints, and Swagger/OpenAPI documentation.
- Configurable PostgreSQL, MySQL, SQLite, and SQL Server database backends.
- Optional Docker Compose development and production setup.
- Optional Celery background processing with Redis or RabbitMQ brokers.
- Optional Flower dashboard for Celery worker/task monitoring, protected by generated basic-auth credentials and bound to localhost by default.
- Configurable console logging and optional Sentry error monitoring.
- Optional object storage integrations for AWS S3, self-hosted Silo (S3-compatible), Google Cloud Storage, and Azure Blob Storage.
- Post-generation setup for environment files and generated secrets.
- Django app-generation helper and per-app unit, integration, and end-to-end test layout.
- CI coverage for generated projects and optional feature combinations.
- Project documentation covering setup, configuration, architecture, security, contribution, and releases.

### Notes
- This is a pre-1.0 release. Prompt choices, generated project structure, and configuration contracts may still evolve.
- Existing projects generated by earlier template revisions are not automatically upgraded; review changes and apply them deliberately.
- No compatibility guarantee is implied across pre-1.0 minor releases.
