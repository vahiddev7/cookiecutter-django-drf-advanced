# Contributing

Issues, bug reports, documentation improvements, and focused pull requests are welcome.

## Before opening a pull request

1. Explain the problem and the expected behavior.
2. Keep optional feature combinations working.
3. Add or update tests for changed behavior.
4. Update documentation when prompts, generated files, or setup steps change.
5. Run the relevant checks locally and report their results.

## Pull request scope

Prefer small, reviewable changes with a clear purpose. Avoid mixing unrelated refactors and feature work. Include migration or compatibility notes when a change affects generated projects.

See the repository's [CONTRIBUTING.md](https://github.com/vahiddev7/cookiecutter-django-drf-advanced/blob/master/CONTRIBUTING.md) for the current contribution policy.
