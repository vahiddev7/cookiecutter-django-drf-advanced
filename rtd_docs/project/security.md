# Security policy

Do not publish credentials, tokens, private keys, or exploitable details in public issues.

For security concerns, follow the private reporting instructions in the repository's [SECURITY.md](https://github.com/vahiddev7/cookiecutter-django-drf-advanced/blob/master/SECURITY.md).

When using a generated project, review Django settings, authentication and authorization, secret management, dependency versions, network exposure, and storage permissions before production deployment.
